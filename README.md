# 🚀 Personal Portfolio Website

A modern, responsive, and interactive **developer portfolio website** built to showcase my skills, internships, certifications, and projects in **Web Development, Full Stack Development, and Cyber Security**.

This portfolio represents my technical journey as a **Full Stack Developer and Cyber Security Enthusiast** with a premium UI design, smooth animations, and responsive layouts.

---

# 🌟 Features

✨ Modern premium portfolio design  
✨ Responsive design for all devices  
✨ Animated UI components  
✨ Interactive project showcase  
✨ Web Development achievements section  
✨ Cyber Security skills and projects section  
✨ Internship and certification showcase  
✨ Smooth navigation using React Router  
✨ Glassmorphism and modern CSS effects  
✨ Component-based React architecture
